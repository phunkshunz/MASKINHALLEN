# Phunkshunz AUDIO · MASKINHALLEN

Hemsida och butik för Phunkshunz AUDIO och techno-serien MASKINHALLEN. Ligger på GitHub Pages.

- `index.html` är sidan som visas.
- `site.html` är samma sida utan ram, för förhandsvisning.
- Köplänkarna fylls i överst i skriptet (`SHOP = { … }`). En plugin utan länk visar "Coming soon" automatiskt.
  Nycklar: `betong`, `armering`, `fukt`, `kolv`, `smuts`, `valv`, `mindbender`, `betongFukt`, `alla` (BETONG + ARMERING + FUKT), `komplett` (alla sju).
- Swish-numret och priserna i kronor står i `SWISH = { … }`.
